SummerTrip 游玩说明
====================

欢迎游玩《SummerTrip》。

这是一段以秋姐妹为主角的短篇视觉小说序章。你将作为一名误入妖怪之山山脚的旅人，在秋穰子与秋静叶的帮助下，调查被打乱的季节异常，并在故事中做出不同选择。

启动方法
--------
解压游戏压缩包后，双击 SummerTrip.exe 即可开始游戏。

请尽量不要单独移动或删除游戏目录中的文件，否则可能导致游戏无法正常运行。

基本操作
--------
鼠标左键 / Enter / Space：推进文本、确认选择
鼠标右键 / Esc：打开或关闭游戏菜单
鼠标滚轮上滑：回看之前的文本
Ctrl：快进已读文本
H：隐藏对话框，欣赏画面

存档说明
--------
游戏菜单中可以进行保存、读取、设置音量、调整文字速度等操作。
建议在分支选择前手动保存，方便体验不同选项。

游玩提示
--------
本版本为序章体验版，流程较短，包含多个选择分支。
不同选项会影响你更接近秋穰子、秋静叶，或更关注季节异常的真相。

祝你旅途愉快。
