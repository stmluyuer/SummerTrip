SummerTrip 序章体验版说明
==========================

版本：0.1.0-prologue
推荐平台：Windows PC（Linux / macOS 尚未完成发布验证）
推荐分辨率：1920x1080

欢迎游玩《SummerTrip》。

这是一段以秋姐妹为主角的短篇视觉小说序章。你将作为误入妖怪之山山脚的旅人，在秋穰子与秋静叶的帮助下调查被打乱的季节异常，并在故事中进入不同的序章结尾。

启动方法
--------
解压发布包后，双击 SummerTrip.exe 即可开始游戏。

请保持发布包内的目录结构完整，不要单独移动或删除 game、lib 等目录，否则可能导致游戏无法正常运行。

基本操作
--------
鼠标左键 / Enter / Space：推进文本、确认选择
鼠标右键 / Esc：打开或关闭游戏菜单
鼠标滚轮上滑：回看之前的文本
Ctrl：快进已读文本
H：隐藏对话框
S：截图

存档说明
--------
游戏菜单中可以保存、读取、调整音量、调整文字速度和切换自动前进。
建议在分支选择前手动保存，方便体验三条序章结尾：

- 穰子路线开端
- 静叶路线开端
- 姐妹共同行动路线开端

素材与发布说明
--------------
当前版本是序章体验与 Godot 迁移的行为基准，资源加载保持 Ren'Py 原生方式。
仓库尚未补全背景、角色、UI 和字体的作者、来源、许可证及再发布范围；授权清单完成前，不应将仓库素材视为可公开再发布资产。
项目内的 source 与 unused 素材不会进入正式构建包。

祝你旅途愉快。
