# SummerTrip Godot 功能对等验收表

目标结构见 `godot_architecture.md`，实施顺序见 `godot_implementation_roadmap.md`，迁移输入见 `godot_migration_inventory.md`。

状态说明：

- `已整理`：迁移输入和验收标准已经明确。
- `未开始`：Godot 工程中尚未实现。
- `阻塞`：依赖尚未创建或需要产品决定。
- `完成`：已在 Godot 编辑器和导出包中验证。

## 7. 回归路线

至少验证以下六条路径：

1. 感谢穰子 → 陪穰子取作物 → 触碰草痕 → 穰子结尾。
2. 感谢穰子 → 听静叶说明 → 先取作物 → 静叶结尾。
3. 询问叶片异常 → 立即调查 → 检查作物 → 姐妹结尾。
4. 询问叶片异常 → 先取作物 → 观察红叶 → 穰子结尾。
5. 提到钟声 → 询问秋祭 → 静叶结尾。
6. 提到钟声 → 前往钟声方向 → 触碰草痕 → 姐妹结尾。

每条路线至少在以下位置各执行一次存档和读取：

- 第一处三选项出现前。
- 红叶树调查三选项出现前。
- 最终路线三选项出现前。
- 结尾最后一句显示时。
