# Ren'Py 设置界面复刻方案

## 1. 目标与范围

在 Godot 4.7.1 .NET 迁移工程中复刻 Ren'Py 的设置界面，基准分辨率为
1920×1080。复刻范围包括设置页的公共游戏菜单外壳、左侧导航、设置控件、鼠标与
键盘交互、设置持久化，以及设置项对剧情运行时的实际影响。

本阶段只要求设置页达到像素级一致。左侧导航会接入现有历史、保存、读取、关于等
功能，但这些目标页面本身不在本阶段进行像素级重制。

`game/` 是只读行为与视觉基准，不修改原版 Ren'Py 文件。

## 2. Ren'Py 事实来源

- `game/screens.rpy` 的 `navigation()` 定义标题/游戏菜单导航。
- `game/screens.rpy` 的 `game_menu()` 定义背景、420px 导航区、标题、返回按钮和
  右侧内容容器。
- `game/screens.rpy` 的 `preferences()` 定义显示、快进、文字速度、自动前进、
  三类音量和全部静音。
- `game/gui.rpy` 定义 1920×1080 基准、字号、间距和滑条尺寸。
- `game/ui_theme.rpy` 与 `game/ui_screens.rpy` 定义项目覆盖色、导航描边和标题色。
- `game/gui/game_menu.png`、`game/gui/overlay/game_menu.png`、
  `game/gui/button/` 和 `game/gui/slider/` 是最终运行素材。
- 用户提供的 Ren'Py 截图是样式初始化顺序出现差异时的最终视觉权威。

## 3. 视觉基准

- 基准分辨率：1920×1080。
- 公共菜单顶部留白：180px；底部留白：45px。
- 左侧导航区宽度：420px；导航 x 坐标：68px。
- 内容区左边距：60px；右边距：30px；顶部边距：15px。
- 标题 x 坐标：75px；高度：180px；字号：75px。
- 普通界面文字字号：33px；设置标签字号：36px。
- 上半区每列宽度：338px；滑条区每列宽度：675px。
- 滑条尺寸：525×38；单选/复选前景尺寸：27×49。
- 原版底图 `#2f3b3f` 与 80% 黑色遮罩合成最终暗色背景；蓝色分隔线直接使用
  `overlay/game_menu.png`，不重新近似绘制。

Godot 使用现有 `canvas_items` 拉伸策略。1920×1080 下使用准确像素值，其他窗口
尺寸按画布等比缩放。

## 4. Godot 实现设计

### 4.1 素材与主题

菜单背景、遮罩、单选、复选和水平滑条源图均为纯色矩形。Godot 以 ColorRect、
StyleBox 和可审查 SVG 按源图的准确尺寸、像素边界与 RGBA 值表达同一结果，避免引入
无法用文本补丁审查的重复二进制副本。等价 SVG 单独登记在迁移清单。新增菜单专用
Theme，避免设置页样式污染剧情对话和快捷菜单使用的 `vn_theme.tres`。

### 4.2 设置页

重建 `features/settings/settings_screen.tscn`：

- 全屏原版背景和遮罩。
- 左侧导航、标题与返回按钮。
- “窗口/全屏”文本单选。
- “未读文本/选项后继续/忽略转场”文本复选。
- 原版文字速度、自动前进、音乐、音效、语音滑条。
- 原版样式的“全部静音”。
- 移除 Godot 旧页中的数值标签和“恢复默认”按钮。

### 4.3 导航上下文

设置页接收标题菜单或游戏内菜单上下文：

- 游戏内：历史、保存、读取游戏、设置、标题菜单、关于、帮助、退出、返回。
- 标题菜单：开始游戏、读取游戏、设置、关于、帮助、退出、返回。

设置页只发出导航请求，由 `GameRoot` 继续作为场景切换、确认弹窗和会话生命周期的
唯一协调者。游戏内保存/读取仍遵守当前交互状态门禁。

### 4.4 设置语义

- 文字速度范围为 0–200 字/秒，0 表示瞬间显示；默认值沿用 Ren'Py 项目的 1。
- 自动前进参数范围为 0–30；0 表示不自动前进，默认值沿用 Ren'Py 项目的 30。
- 自动前进等待按 Ren'Py 规则随当前文本长度变化，而不是固定秒数。
- 快进未读文本和选项后继续保持当前已实现语义。
- 新增 `TransitionsEnabled`；“忽略转场”选中时其值为 `false`。
- 音量继续映射 Music、Sound、Voice 总线；全部静音同时控制三条总线。

旧版 `settings.json` 中的 `auto_wait_seconds` 会在读取时迁移，避免升级后重置用户其他
设置。新文件保存为明确的自动前进参数字段。

### 4.5 忽略转场

`StageController` 在每次 `change_scene` 时读取设置：

- 启用转场时保持当前 `slow_dissolve` 和 `scene_blend`。
- 忽略转场时立即应用背景与叠色，不启动场景 Tween。
- 仍更新 TransitionId、角色清理、叠色动画和存档快照。

## 5. 验收标准

### 5.1 视觉

- 在 1920×1080 截图上逐项对照 Ren'Py 基准。
- 背景、分隔线、radio、check 和 slider 使用相同源素材。
- 主要控件位置误差不超过 2px。
- 字体、字号、颜色、选中、悬停、禁用和键盘焦点状态一致。
- 在 1280×720 再验证缩放和点击区域。

### 5.2 功能

- 窗口/全屏、文字速度、自动前进、快进策略、忽略转场、音量和静音即时生效。
- 重启后设置保持。
- 旧设置文件可迁移。
- 左侧所有入口可用；Esc/返回回到正确的标题或游戏状态。
- 标题菜单不能保存，游戏内保存/读取仍遵守稳定交互门禁。

### 5.3 工程验证

- 资源清单：`./tools/check_assets.ps1`。
- C# 构建：在 `godot/` 下运行 `dotnet build SummerTrip.csproj`。
- 使用 Godot 4.7.1 .NET 控制台程序重新导入。
- 运行 M6 菜单设置测试、M7 AVG 功能测试和序章 smoke。
- 实际启动并截取设置页进行视觉对照。

## 6. 发布限制

设置页使用的原版 UI 素材当前在 `asset_licenses.tsv` 中仍为
`unverified / local_validation_only`。本次可以完成本地迁移与视觉验收，但在授权补齐
前不得把 `-RequireVerifiedLicenses` 或公开发布门禁声明为通过。
